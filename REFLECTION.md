# Reflection

This mini project helped me understand how Business Intelligence can be used to convert raw sales data into meaningful information for decision making. I learned how to import and transform data using Power Query and organize it into a star schema with a fact table and dimension tables. Creating relationships between Dim_Date, Dim_City, Dim_Product, and Fact_Sales helped me understand how a proper data model supports interactive analysis.

I also learned how DAX measures can be used to calculate business metrics such as Total Sales, Month-over-Month Sales Growth, Running Total Sales, Item Rank, and Average Transaction Value. Building these measures improved my understanding of time-based calculations, ranking, and aggregation.

Creating the dashboard helped me understand how visualizations, slicers, and drill-down features can make sales analysis more interactive. The Cold Brew trend, city performance comparison, and category analysis provided different views of the sales data.

Git and GitHub helped me understand version control and the importance of maintaining a clear project history. Making separate commits for the schema, DAX measures, dashboard, and documentation made the development process organized.

GitHub Copilot was useful for generating initial DAX suggestions and helping with documentation. I learned that Copilot suggestions should always be checked against the actual data model and dashboard before using them. Overall, this project improved my practical skills in Power BI, DAX, GitHub, and BI-based decision making.
